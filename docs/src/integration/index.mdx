LVGL is a bunch of C and header files that you can easily add and compile in your project.

This section is about **getting LVGL into your environment** --- the platform, the toolchain, the
build system, the vendor SDK. Each page ends by pointing at the drivers and renderers that
environment calls for.

## Where to Start

| You are targeting | Start here |
|---|---|
| A PC, to try LVGL out | [Running on PC](/integration/pc) |
| Embedded Linux hardware | [Embedded Linux](/integration/embedded_linux) |
| An RTOS — FreeRTOS, Zephyr, NuttX, QNX… | [RTOS Support](/integration/rtos) |
| A specific chip — STM32, ESP32, NXP, Renesas, Alif | [Chip Vendor Support](/integration/chip_vendors) |
| Arduino, PlatformIO or Tasmota | [Framework Support](/integration/frameworks) |
| A specific development board | [Board Support](/integration/boards) |
| A language other than C | [Bindings](/integration/bindings) |

Then configure the library ([Configuring LVGL](/integration/configuration)) and wire it into your
build ([Build System Support](/integration/building)).

## Connecting to Hardware

Writing a custom display and input device from scratch is easy, but you can also pick from
ready-to-use drivers. These are documented under **Main Modules**, because which one you need
depends on your hardware rather than on your development environment:

- **[Display Drivers](/main-modules/display_drivers)** — OS backends
  ([DRM](/main-modules/display_drivers/drm), [Wayland](/main-modules/display_drivers/wayland),
  [SDL](/main-modules/display_drivers/sdl), [Windows](/main-modules/display_drivers/windows)…),
  SoC controllers ([ST LTDC](/main-modules/display_drivers/st_ltdc),
  [NXP eLCDIF](/main-modules/display_drivers/nxp_elcdif),
  [Renesas GLCDC](/main-modules/display_drivers/renesas_glcdc)) and external
  [LCD controllers](/main-modules/display_drivers/lcd) such as
  [ILI9341](/main-modules/display_drivers/lcd/ili9341).
- **[Input Drivers](/main-modules/input_drivers)** —
  [evdev](/main-modules/input_drivers/evdev) and
  [libinput](/main-modules/input_drivers/libinput), plus which display drivers already bring
  input with them.
- **[Renderers and GPUs](/main-modules/renderers)** — the
  [software renderer](/main-modules/renderers/sw) and every GPU draw unit LVGL supports.

All the mainstream RTOS and desktop operating systems are supported, including
[FreeRTOS](/integration/rtos/freertos), [Zephyr](/integration/rtos/zephyr),
[NuttX](/integration/rtos/nuttx), [Windows](/integration/pc/windows),
[Linux](/integration/pc/linux) and [macOS](/integration/pc/macos).

You can also pick a [ready-to-use project](https://lvgl.io/boards) for many development boards.
