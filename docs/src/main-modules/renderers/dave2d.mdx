## Overview

[Dave2D](https://www.renesas.com/document/mas/tes-dave2d-driver-documentation) (also written as
D/AVE 2D) is a 2D GPU developed by TES. It is found in **Renesas RA and RZ/A** devices and in
**Alif Ensemble** chips. Both platforms expose the same D/AVE 2D driver API, so LVGL uses one
built-in draw unit for both.

Accelerated operations are dispatched to the GPU while the CPU stays free to run the rest of the
application.

## Configuration

Enable <ApiLink name="LV_USE_DRAW_DAVE2D" />.

```c
#define LV_USE_DRAW_DAVE2D 1
```

There is nothing else to do. No platform-specific function needs to be implemented and no drawing
code needs to be changed.

### Options

| Symbol | Default | Effect |
|---|---|---|
| `LV_DAVE2D_MAX_DRAW_PRESSURE` | `256` | How many pending draw tasks are collected into one display list before it is submitted to the GPU. `256` is also the minimum — with smaller values the Dave engine may crash. |

### Prerequisites

On **Renesas**, the D/AVE 2D driver has to be added to the project in the `Configuration Window`
of e² studio. The LVGL draw unit includes the FSP headers `bsp_api.h` and `dave_driver.h`, so
missing this step causes a compilation error. The boards LVGL maintains a project for already
have the driver configured — see [RA Family](/integration/chip_vendors/renesas/ra_family) and
[RZ/A Family](/integration/chip_vendors/renesas/rza_family).

On **Alif**, the [alif_m55-lvgl](https://github.com/alifsemi/alif_m55-lvgl) project used in the
[Alif overview](/integration/chip_vendors/alif/overview) already has the draw unit enabled, so it
accelerates rendering out of the box.

## Accelerated Operations

Dave2D can accelerate most of LVGL's [drawing](/main-modules/draw/draw_pipeline) operations:

- Rectangle drawing, even with gradients
- Image drawing, scaling, and rotation
- Letter drawing
- Triangle drawing
- Line drawing

Everything Dave2D cannot handle is rendered by the
[software renderer](/main-modules/renderers/sw), so no operation is lost by enabling the GPU.

### Supported image color formats

Images are accelerated in the following color formats:

- <ApiLink name="LV_COLOR_FORMAT_A8" />
- <ApiLink name="LV_COLOR_FORMAT_RGB565" />
- <ApiLink name="LV_COLOR_FORMAT_ARGB1555" />
- <ApiLink name="LV_COLOR_FORMAT_ARGB4444" />
- <ApiLink name="LV_COLOR_FORMAT_ARGB8888" />
- <ApiLink name="LV_COLOR_FORMAT_XRGB8888" />

<Callout type="info">
<ApiLink name="LV_COLOR_FORMAT_RGB888" /> is a 3 byte format, while the matching Dave2D mode is
a 4 byte format. Therefore RGB888 images are drawn by the software renderer.
</Callout>

## Support

| Capability | Value |
|---|---|
| Hardware | Renesas RA / RZ-A, Alif Ensemble |
| Vector graphics | No |
| 3D / glTF | No |
| Fallback | Software renderer handles unsupported tasks |
