The LVGL Barcode utility enables you to generate Code-128 bar codes.  It uses the
[code128](https://github.com/fhunleth/code128) library by
[fhunleth](https://github.com/fhunleth).

## Usage

Set <ApiLink name="LV_USE_BARCODE" /> to `1` in `lv_conf.h`.

Use <ApiLink name="lv_barcode_create" /> to create a barcode object, and use
<ApiLink name="lv_barcode_set_data" /> to set the data to encode.

### Set Data

<ApiLink name="lv_barcode_set_data" display="lv_barcode_set_data(barcode, &quot;some data&quot;)"/> sets the data to encode
on the barcode. A copy of the data is stored, so the other properties can be set before or after it.
An empty string or `NULL` clears the barcode.

### Scale

Call <ApiLink name="lv_barcode_set_scale" /> to set the thickness of each bar in pixels. The default is `1`.

### Direction

Call <ApiLink name="lv_barcode_set_direction" /> with `LV_DIR_HOR` (default) or `LV_DIR_VER`
to set which way the bars run.

### Sizing

The size of the barcode can be set as for any other widget, with <ApiLink name="lv_obj_set_width" />,
<ApiLink name="lv_obj_set_height" />, or by a layout.

For a horizontal barcode the bars are centered horizontally and fill the height of the content
area (the widget's height minus `pad_top` and `pad_bottom`). The default width is `LV_SIZE_CONTENT`,
which makes the widget exactly as wide as the bars with the given scale (plus the horizontal padding).

The same applies to a vertical barcode with the width and height swapped.

<Callout type="info">
  If the content area is too small to fit all the bars with the given scale, the barcode is not drawn.
</Callout>

### Colors

Call <ApiLink name="lv_barcode_set_dark_color" /> and <ApiLink name="lv_barcode_set_light_color" />
to adjust colors. Changing the colors doesn't regenerate the bars.

### Encoding

By default, <ApiLink name="LV_BARCODE_ENCODING_CODE128_GS1" /> encoding is used
which strips `[FNC1]` and spaces. Optionally use
<ApiLink name="lv_barcode_set_encoding" /> to set
<ApiLink name="LV_BARCODE_ENCODING_CODE128_RAW" />.
